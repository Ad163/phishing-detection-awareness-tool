# Tables — naming convention

All tables produced during this project are saved here as CSV, named:

```
T<NN>_<short_description>.csv
```

- `T01`–`T10` — reserved for dataset/EDA tables (Objective O1), produced by `src/data/eda.py`
- `T11`–`T29` — reserved for model comparison tables (Objective O2): precision/recall/F1/AUC-ROC per model, etc.
- `T30`–`T49` — reserved for prototype/tool testing tables (Objective O3)
- `T50`–`T69` — reserved for evaluation study tables (Objective O4): demographics, SUS scores, NASA-TLX scores
- `T70`–`T89` — reserved for statistical analysis tables (Objective O5): paired t-test results, effect sizes, correlations
- `T90`+ — reserved for any late-addition/appendix-only tables

Numbers are not reused even if a table is dropped later — skip forward rather than renumber, so citations to `Table T05` etc. in the dissertation text stay stable once written.

## Note: this T-numbering is for computed/empirical result tables only

Narrative comparison tables that live inside a chapter's argument (e.g. a literature gap-analysis matrix, a qualitative model comparison table in the Literature Review) are NOT part of this series. Those are authored directly in the relevant chapter's Markdown source (`writing/chapters/0N_name.md`, using standard Markdown table syntax) and numbered by chapter instead (Table 2.1, Table 2.2, etc.), since they are integral to that chapter's prose rather than a standalone generated artefact. `src/writing/md_to_docx.py` renders Markdown tables as real Word tables automatically. Chapter 2 currently has two: Table 2.1 (ML model comparison) and Table 2.2 (literature gap matrix).
